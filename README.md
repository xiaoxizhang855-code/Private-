# WBS-40 招聘测评网站 V4.2

本发布包沿用原 WBS-40 网站界面与候选人作答、结果卡、HR 正式报告、招聘后台和在线数据存储功能，题库已更新为大五人格 20 个子维度版本。

## 当前测评结构

- 40 道大五子维度题：20 个子维度，每个子维度 2 道正反向题。
- 26 道原创职场情景题：每题 5 个选项，统一映射大五五维。
- 共 66 道正式题目。
- 模型版本：`BIG5-20-FACETS-1.0`
- 算法版本：`WBS-BIG5-20-DISC-4.2`
- DISC 仅作辅助分析，不参与大五人格计分。

## Netlify 发布

1. 解压 ZIP，并将本目录中的全部内容上传到 GitHub 仓库根目录。
2. 在 Netlify 中导入该 GitHub 仓库。
3. Netlify 会读取 `netlify.toml`；构建命令为 `npm run build`，发布目录为 `public`，Functions 目录为 `netlify/functions`。
4. 在线候选人报告、HR 报告和后台记录依赖 Netlify Functions 与 Netlify Blobs，因此不要只上传 `public` 文件夹，也不要使用仅支持静态文件的 Netlify Drop 代替完整部署。
5. 当前内部审核密码为 `11123`。正式使用前应改为企业独立强密码，并限制 HR 后台访问人员。

## 本地预览

直接打开 `public/index.html` 即可预览和作答。本地模式使用浏览器 `localStorage` 保存记录；更换浏览器、清理浏览器数据或更换电脑后，本地记录不会保留。

## 使用边界

该版本适合内部审核和小规模试用。正式用于招聘决策前，仍需完成信度、效度、公平性、本地常模和数据合规验证，并保留人工复核渠道。
